## How to Deploy

### Option 1: Free hosting with Netlify
1. Go to https://app.netlify.com
2. Drag and drop this folder
3. Your site is live at a .netlify.app URL
4. Connect your custom domain if you have one

### Option 2: Free hosting with GitHub Pages
1. Create a GitHub repository
2. Push these files
3. Enable GitHub Pages in repo settings
4. Live at yourusername.github.io/reponame

### Option 3: Any static hosting
Upload index.html, styles.css, and scripts.js to any web host.
